# AlgoVision

## Interactive Algorithm Visualization & Performance Analysis

AlgoVision is a Python-based desktop application that visually demonstrates sorting algorithms through animated bar charts and real-time performance metrics.

The project is designed to make sorting algorithms easier to understand by showing how elements are compared, swapped, and moved during execution.

## 🚀 Features

- Visual animation of sorting algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Custom dataset input
- Random dataset generation
- Adjustable visualization speed
- Pause and Resume functionality
- Reset functionality
- Live comparison count
- Live swap count
- Live operation count
- Real-time algorithm code highlighting
- Time and space complexity analysis
- Clean dark-themed graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- NumPy
- Matplotlib

## 📊 Algorithms Implemented

### Bubble Sort
Repeatedly compares adjacent elements and swaps them when they are in the wrong order.

- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)
- Space Complexity: O(1)

### Selection Sort
Finds the minimum element from the unsorted portion and places it in the correct position.

- Best Case: O(n²)
- Average Case: O(n²)
- Worst Case: O(n²)
- Space Complexity: O(1)

### Insertion Sort
Builds the sorted portion of the array one element at a time.

- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)
- Space Complexity: O(1)
